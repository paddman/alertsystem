# Delivery Roadmap

## Phase 1 — Core MVP

- Workflow definitions and immutable versions
- Case lifecycle API
- Human task and approval inbox
- Agency-aware RBAC
- Append-only audit trail
- Docker Compose deployment

## Phase 2 — Government operations

- OIDC/SAML and government digital identity integration
- Delegation, acting roles, and organizational hierarchy
- SLA, escalation, and work calendars
- e-Form builder and document templates
- Notification center
- Search and executive dashboards

## Phase 3 — Integration platform

- Connector catalog and approval workflow
- n8n private adapter
- Node-RED edge adapter
- API management, rate limits, and schema registry
- Secrets manager integration
- OpenTelemetry and SIEM export

## Phase 4 — AI-assisted services

- Local AI gateway
- PII detection and redaction
- Document classification and extraction
- RAG over approved government knowledge
- Human review queue and model/prompt audit

## Phase 5 — Production assurance

- HA deployment and autoscaling
- Backup, immutable storage, and DR site
- Security testing and supply-chain controls
- Performance, accessibility, and localization testing
- Agency onboarding and migration toolkit
